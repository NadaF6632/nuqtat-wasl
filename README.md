# Nuqtat Wasl | نقطة وصل

**A Saudi Real Estate Web Platform**

Nuqtat Wasl is a web-based real estate platform developed as an Information Technology graduation project. It aims to simplify property discovery and listing management by connecting property owners with people looking to buy or rent properties.

## Overview

Finding and managing real estate listings can be complicated when property information is scattered across different platforms. Nuqtat Wasl aims to provide a centralized platform where users can explore properties and owners can manage their listings.

The project focuses on a user-friendly experience, organized property information, and features designed around the needs of buyers, renters, property owners, and administrators.

## Key Features

* **Property Listings:** Browse real estate listings and view property details.
* **Property Search:** Find properties using available search and filtering options.
* **Interactive Map:** Explore property locations using mapping functionality.
* **User Accounts:** Support different user roles and access levels.
* **Property Management:** Provide property owners with tools to manage their listings.
* **Administrative Management:** Support administrative review and management workflows.

*Note: The availability of each feature depends on the implemented version of the project.*

## User Roles

* **Searchers(Buyers and Renters):** Explore available properties.
* **Property Owners:** Manage property listings and related information.
* **Administrators:** Review and manage platform activities.

## Getting Started

### Prerequisites

* Node.js and npm
* PostgreSQL
* A modern web browser

### Installation

1. Clone or download this repository.

2. Open the `backend` directory in your terminal.

3. Install the project dependencies:

   ```bash
   npm install
   ```

4. Configure the database connection using your local PostgreSQL setup.

5. Create and configure the required database.

6. Start the backend using the start command defined in `package.json`.

7. Open the frontend using your preferred local development server.

Refer to the backend configuration and available project scripts for the exact database setup and startup commands.
